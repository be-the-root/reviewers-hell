
# reviewers hell

so this is a small horror puzzle game i made. you're a reviewer and you have to find one specific page. most of the buttons lie. good luck lol.




## what is this

its just a bunch of html pages connected by buttons. u click through them, read weird text, and try to find the page that says **"this is the two!!!!"**. thats the whole game.

i made it to mess with whoever reviews my project. sorry (not sorry).

---

## tech stack

- **html5** - all the pages
- **css3** - flexbox, keyframes, red on black. no frameworks
- **no javascript** - its just static pages connected by links
- **no build tools** - no npm, no webpack, no nothing. just open the file and it works



## live demo

hosted on github pages

## how to run it

just download the files and open `index.html` in your browser. thats it.

if something acts weird, use a local server:

```
python -m http.server 8000
```

then go to `localhost:8000`.

---

## how to play

- click buttons
- read stuff
- some buttons dont take u where they say
- find the right page and u win
